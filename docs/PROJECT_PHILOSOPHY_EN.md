# Project Philosophy

This document describes the philosophy, positioning and direction of the M.A.R.I.A. ecosystem.

## Rebirth

Maria has passed the stage where the project needed to prove it was more than another chatbot prototype.

The New Horizon era established the runtime foundation: memory, relationship state systems, capability boundaries, manager-layer architecture, social perception, voice runtime, debug API and public showcase.

Rebirth is the next chapter.

Its goal is not to add even more rigid restrictions.
Its goal is to allow Maria to grow beyond the scaffolding that earlier weaker models required.

The project now moves toward:

- Maria perception instead of objective message classification;
- scene possibilities instead of mechanical reaction commands;
- actor-model behavior instead of rigid if-else routing;
- authored persona reaction profiles;
- cleaner memory and observable runtime;
- a clearer separation between public engine and private identity.
